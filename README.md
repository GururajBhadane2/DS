# Data Structures & Algorithms (DSA)

Comprehensive implementations for Data Structures & Algorithms, SPPU Laboratory Practicals (Groups A–D), Unit-wise syllabus code, and DS Syllabus Mastery with Viva prep.

## 📁 Repository Structure

- **[DSA/Unit_I_Arrays_and_Linked_Lists](DSA/Unit_I_Arrays_and_Linked_Lists)**: Array operations, 2D addressing, Singly, Doubly, and Circular Linked Lists.
- **[DSA/Unit_II_Searching_and_Sorting](DSA/Unit_II_Searching_and_Sorting)**: Linear & Binary search, Bubble, Selection, Insertion, Quick, and Merge sort.
- **[DSA/Unit_III_Stack](DSA/Unit_III_Stack)**: Stack implementations (Array & Linked List), Infix/Postfix/Prefix conversion & evaluation, Call stack simulation.
- **[DSA/Unit_IV_Queue](DSA/Unit_IV_Queue)**: Linear & Circular queues, Deque, Priority queue, Round Robin CPU scheduling.
- **[DSA/Group_A](DSA/Group_A)** to **[DSA/Group_D](DSA/Group_D)**: Complete practical assignment implementations with user-friendly menu-driven systems.
- **[DSA/DS_Syllabus_Mastery](DSA/DS_Syllabus_Mastery)**: Level 1 to Level 5 progressive coding challenges & comprehensive Viva preparation guide.
- **[DSA/z_EXTRA](DSA/z_EXTRA)**: Archived practicals, assignments, and test programs.
